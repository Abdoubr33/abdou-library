# 🌙 Moonlight Library

A beautiful digital library website with 1000 books to explore and read!

## ✨ Features

- 📚 **1000 Books** - Explore a vast collection of books across 11 genres
- 🔍 **Search & Filter** - Find books by title, author, or genre instantly
- 📖 **Built-in Reader** - Read books directly in the browser with adjustable font size
- 🎵 **Background Music** - Enjoy relaxing music while browsing
- 🎨 **Beautiful UI** - Modern, dark theme design with smooth animations
- 📱 **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- ⚡ **Fast & Smooth** - No external dependencies, pure HTML/CSS/JavaScript

## 🚀 How to Use

1. **Browse Books** - Scroll through the library and click on any book to read
2. **Search** - Use the search bar to find books by title, author, or genre
3. **Filter by Genre** - Click category buttons to filter by genre
4. **Read** - Click a book to open the reader
5. **Adjust Font** - Use A- and A+ buttons to adjust text size
6. **Music** - Click the music button to play/pause background music

## 🎵 Adding Background Music

To add background music:
1. Add your `chill.mp3` file to the project folder
2. The player will automatically play it when you click the music button
